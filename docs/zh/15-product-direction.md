# 产品方向与方案取舍（2026-11-27）

## 1. 方向与近期承诺

长期方向：开放的 AI 能力执行运行时与插件生态，具备可嵌入、可扩展和可互操作能力。首批用户是将已有应用能力提供给 AI 或预设任务的开发者。Android 是首个可验收宿主，纯 JVM 契约和平台适配边界继续保留。

近期承诺是：宿主能注册自己的能力，通过同一 Runtime 完成预览、确认、实际执行、产物与失败反馈。独立记录导出示例是首个参考实现，不代表已有外部应用采纳或形成插件生态。

## 2. 对整体改造建议的处理

| 建议 | 决策与现状 |
|---|---|
| Core / Adapter / Extension / Services 分组 | 接受为逻辑职责划分；保留现有 artifact 名称 |
| Runtime 不依赖模型或市场运行 | 基础宿主装配不初始化两者；构建依赖解耦待完成 |
| Command Protocol 平台无关 | 保持现有 DSL/Typed IR、错误码和版本规则；新 JSON 信封需单独 RFC 与迁移 |
| 新 Manifest、Plugin 生命周期 | 先映射现有 PluginManifest、PluginLoader、安装状态和 onLoad/onUnload，避免并行定义两套真相 |
| Workflow / Memory 可选化 | 目标接受；先审查 RuntimeGateway、工作流授权、实体展开和持久恢复的依赖再抽取 |
| Plugin Testkit / CLI | 先复用现有 conformance 与宿主回归；新增工具以外部开发者真实接入摩擦为依据 |
| MCP 双向集成 | 保留入站工具适配；对外暴露命令前先设计身份、作用域、执行句柄和确认交互 |
| 多平台与市场增长 | 在独立宿主和第三方插件验证后推进 |

方案示例中的 `system.get_battery`、`device.camera.capture`、`protocolVersion`、`capabilities` 等不构成当前 API。现有命令仍以实际描述符为准，例如 `sys.device.battery` 和 `camera.capture`。不通过文案修改引入静默破坏。

## 3. 下一批交付与验收

1. 完成本轮独立宿主的设备验证，记录实际产物、拒绝和取消；区分 JVM 与设备证据。
2. 裁剪基础宿主的 Gradle 制品依赖，提供旧 CompositionRoot/AppDeps 接入迁移说明；基础示例仍需通过。
3. 形成一个可脱离主仓库构建的自定义插件示例，复用 manifest/conformance 测试与发布流程。
4. 统一业务 runId 与审计关联，补提前拒绝/校验失败的持久诊断策略。
5. 引入第二个独立业务宿主后，再确定 MCP 对外适配与插件生命周期 API 的稳定面。

“5 分钟接入”“30 分钟开发插件”“2 个独立应用”“3 个外部作者插件”作为待验证目标，不能标记为已达成。版本号依据真实兼容性和发布门禁决定，不按固定周数承诺 1.0。

## 4. 安全与兼容性边界

基础宿主只加载随 App 发布的可信插件。Android 同 UID 独立进程提供崩溃和内存边界，不能视为针对恶意代码的完整 OS 安全沙箱。宿主业务 API 的授权、系统权限和 Runtime 审批各自有效。

现有协议 fixture 与安全门禁继续约束改造。新构建模块不意味着新协议版本；公开契约破坏性调整必须记录迁移，保留旧制品的可用路径。

## 5. 已确认的下一阶段：ADB 设备控制原型

2026-11-27 用户确认：先收口当前宿主闭环，再以“Agent 通过 ADB 观察、操作并验证 Android 手机任务”为主场景。上述依赖裁剪等仍保留为后续工程事项，ADB 原型优先进入下一轮。

原型范围：显式选择设备、连接状态与超时，获取截图和 UI 树，按 UI 观察结果点击/输入/滑动/返回/启动应用，操作后重新观察并报告验证结果。先提供本地开发者 CLI，再决定 MCP 接入；用户授权 ADB 是前提，Companion 和跨平台控制后续评估。

验收任务使用当前记录导出宿主：观察页面 → 定位导出按钮 → 处理确认 → 检查完成状态与实际文件。执行动作成功不等于业务任务成功；截图、UI 状态和产物分别提供证据。

设备适配放在平台边缘，通用 Runtime 继续拥有命令校验、执行状态和审计。现有宿主能力模式继续提供原生 API 路径；不会因为新的主场景改变既有命令或发布制品契约。

首个本地 ADB CLI 已实现示例 App 的观察、启动、点击和产物验证。手机上的审批由宿主 Runtime 处理。通用手势、截图和 MCP 接入属于后续范围。参见 [ADB 原型](../../tools/mcos-device/README.md)。
